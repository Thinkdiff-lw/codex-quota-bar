# Codex 额度条 · Windows 分享版

## 使用方法

1. 将整个压缩包解压到一个固定文件夹，例如桌面的“Codex额度条”。不要直接在压缩包内运行。
2. 打开已安装的 Codex Windows 桌面版，并登录自己的 ChatGPT 账户。
3. 双击 `启动额度条.cmd`，也可以直接双击 `CodexQuotaBar.exe`。
4. 切回 Codex，额度条会显示在窗口底部。第一次位置不合适时，按住额度条左键拖动即可。

适用于 Windows 10/11，需要系统的 .NET Framework 4.8。程序为免安装版本，不需要 Python、Node.js 或 API Key。

分享版会查找标准安装路径、正在运行的 Codex 桌面版自带 CLI，以及 PATH 中的 `codex.exe`。桌面版和 CLI 请登录同一 ChatGPT 账户；如果提示连接失败，可能需要在终端运行 `codex login`。仍找不到 CLI 时，可在工具文件夹里新建 `codex-path.txt`，填写你自己电脑上的 `codex.exe` 完整路径。不要从别人那里复制账户文件。

## 自动跟随启动

可选：双击 `开启自动跟随.cmd`，以后登录 Windows 约 20 秒后，额度条会通过当前用户的任务计划静默启动，在后台等待 Codex。打开 Codex 自动显示，关闭或切换其他软件时隐藏；不需要每次手动开启。额度条右键菜单也可以开关此功能。

双击 `关闭自动跟随.cmd` 取消以后的登录启动。结束当前运行实例仍用 `退出额度条.cmd`；手动退出后，当前登录期间需重新启动一次。启用后不要移动程序文件夹；若移动，请在新位置重新开启自动跟随。

## 功能和操作

- 显示本机 Codex 登录账户返回的剩余额度，每分钟刷新。
- 紧凑显示时钟图标与重置倒计时、日历图标与具体时间；具体时间使用北京时间。
- 默认融入 Codex 背景，右键 → 外观可以切换深色或浅色。
- 鼠标悬停可以查看完整额度详情；左键拖动调整位置。
- 右键可以立即刷新、切换额度类型、恢复默认位置或退出。
- 切换其他软件或最小化 Codex 时自动隐藏，返回 Codex 时显示。
- 缩放窗口或调整侧栏后，自动跟随输入框底部工具栏的实际空白位置。空间不足时会精简时间信息，避免覆盖权限和模型按钮。重新定位期间可能短暂隐藏。
- 双击 `退出额度条.cmd` 也可以结束程序。

## 常见问题

**没有看到额度条？**

刚登录时等待约 20 秒。开启自动跟随后，任务计划程序中应存在 `CodexQuotaBar-当前用户SID` 任务；`startup.log` 会记录实际启动、就绪和退出事件。新版会自动移除本工具旧的 Run 启动项。若移动过文件夹，请重新双击“开启自动跟随”。

先切回 Codex 窗口。程序只在 Codex 位于前台时显示；系统托盘中也有额度条图标。右键托盘图标可取消“暂时隐藏”或恢复默认位置。

**显示连接失败？**

程序使用本机 Codex CLI 的已有登录状态。如果桌面版和 CLI 登录了不同账户，额度以 CLI 的账户为准。请确认本机 Codex CLI 已用自己的 ChatGPT 账户登录，然后右键“立即刷新”。API Key 登录可能没有套餐额度数据。

**无法找到 Codex？**

程序会查找当前用户的默认 Codex CLI 安装位置和 PATH 中的 `codex.exe`。使用其他安装方式时，可在本文件夹新建 `codex-path.txt`，里面只填写实际的 `codex.exe` 完整路径（不加引号）。

**为什么只显示周额度？**

只显示账户接口实际返回的额度窗口；不会根据套餐猜测未返回的额度。鼠标悬停可以查看各窗口详情。

## 分享与数据

压缩包只包含程序、启动/退出入口、自动跟随开关和本说明，没有制作者的账户、凭证、额度记录或个人路径配置。接收者使用自己的 Codex 登录。

首次运行会在本文件夹生成 `settings.json`，保存位置、主题和额度类型。再次转发时建议直接转发原始压缩包。

这是一款独立的第三方悬浮工具，不是 OpenAI 官方产品。不修改 Codex 安装文件，自动启动由使用者选择开启，也不会消耗额度重置奖励。
