# Codex 额度条

双击 `启动额度条.cmd` 或 `CodexQuotaBar.exe` 启动。只启动一份；退出可通过额度条或系统托盘图标的右键菜单，也可双击 `退出额度条.cmd`。

额度条显示账户实际返回的剩余百分比，每 60 秒刷新。当前只返回周额度时，只显示周额度；鼠标悬停可查看重置时间及上次读取时间。重置时间使用北京时间。读取失败后保留上次数据并标记“数据待更新”，不会把失败当成满额。

新版采用紧凑的无边框状态栏：小圆环表示剩余额度，百分比提高亮度，重置时间降低对比度。默认“融入 Codex 背景”会读取附近少量背景像素匹配颜色，不保存界面截图；也可通过右键 → 外观固定为深色或浅色。鼠标移上去会出现轻微圆角底色和右侧菜单按钮。

时间区域采用紧凑排版：时钟图标配“X天X小时”，日历图标配“月/日 时:分”，两项之间用细线分隔。不足一天改为小时和分钟，每分钟更新倒计时。到达重置时间会显示“等待额度重置”，额度仍以接口返回值为准。空间不足时先隐藏具体日期，鼠标悬停仍可查看。所有标签和数据统一使用微软雅黑 UI，相同字号、常规字重和像素对齐的绘制高度，整行数字共用同一字体与基线；百分比预留固定宽度，分隔线左右间距一致，按 Codex 的 Windows 系统无衬线风格排版。单周额度在主栏显示倒计时；多个额度窗口的重置详情可在悬停提示里查看。

额度条定位到输入框底部“更改权限”和模型选择按钮之间的空白区域。窗口调整大小、侧栏变化和应用缩放后，会重新读取真实控件位置；旧坐标失效期间短暂隐藏，定位完成后显示。后台定位约每 0.6 秒检查一次。读取在独立辅助进程中执行，单次最多等待 5 秒，超时会自动重建并重试；窗口尺寸与 DPI 未变时保留最近 6 秒的有效位置，避免一次慢查询导致持续隐藏。窗口层级在 Codex 位于前台时保持置顶，且不抢输入焦点。空间不足时依次精简具体日期、倒计时；连额度本身也放不下时隐藏，详情仍可从托盘查看。

按住额度条左键可在空白区域内微调，偏移相对输入框保存到 `settings.json`，不会再相对整个窗口计算。右键“恢复默认位置”可重新自动对齐。旧版基于窗口的位置设置会自动迁移为新的默认定位。

切换到其他软件、最小化 Codex 时自动隐藏；回到 Codex 自动显示。多个 Codex 窗口时跟随当前使用的窗口。右键可以立即刷新、切换额度类型、暂时隐藏或退出。

这是独立的 Windows 悬浮窗口，不修改 Codex 安装文件。可选启用当前账户的 Windows 登录任务。数据通过本机 Codex 的官方 app-server 接口读取，复用现有登录状态；不需要 API Key，不读取或保存聊天正文、密码、令牌。只调用初始化和读取额度接口，不发起模型任务或消耗额度重置奖励。

如果显示连接失败，确认 Codex/CLI 已登录，再右键“立即刷新”。桌面版与 CLI 应登录同一 ChatGPT 账户，首次可能需要在终端执行 `codex login`。分享版会从标准安装位置、正在运行的 Codex 自带 CLI 或 PATH 查找；若仍未找到，可在程序目录新建 `codex-path.txt`，填写本机 `codex.exe` 的完整路径。公司账户或 API Key 登录可能不返回此类额度。

## 自动跟随启动

双击 `开启自动跟随.cmd`，或在额度条/托盘右键菜单勾选“随 Windows 登录启动（自动跟随 Codex）”。程序会立即运行，并在以后登录 Windows 约 20 秒后通过任务计划静默启动（仅当前用户，使用已登录的桌面会话）；Codex 未打开时在托盘等待，不定时读取额度。打开 Codex 后自动定位和读取额度，关闭后继续等待下次打开。无需更换 Codex 快捷方式，也不需要管理员权限。

取消时双击 `关闭自动跟随.cmd`，或取消菜单勾选；这只取消以后的登录启动，结束当前程序仍可用“退出额度条”。手动退出后，本次登录期间不会自动复活，下次登录才恢复；若需立即恢复，双击“启动额度条”。启用后请保持程序目录不变；移动目录后，在新目录重新运行“开启自动跟随”。

自动跟随采用 Windows 任务计划，名称为 `CodexQuotaBar-当前用户SID`。开启时会迁移本工具旧的 Run 注册表启动项，不改变其他程序。任务不受电池供电影响，不设运行时长上限；异常退出最多按 1 分钟间隔重试 3 次，正常手动退出不会重启。`startup.log` 仅记录最近 100 条启动/退出/异常类型记录，不包含账户或聊天内容，可用于确认登录任务是否执行。

## 维护

源文件为 `QuotaBar.cs`。运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1` 编译；使用 Windows 自带 .NET Framework，不需要安装包或下载依赖。

运行 `CodexQuotaBar.exe --self-test` 检查额度解析（结果见 `test-result.json`）。运行 `CodexQuotaBar.exe --diagnose` 读取真实额度并检查 Codex 窗口（结果见 `diagnostics.json`）。诊断文件只保存显示数据和窗口几何，不保存凭证。
