# Codex 额度条 · Mac 使用说明

适用于 macOS 13 或更新版本，提供 Apple Silicon / Intel 通用应用。Mac 版为测试版，定位和自动登录启动需要在实际 Mac 上验证。

## 1. 安装并打开

1. 从 GitHub Releases 下载 `CodexQuotaBar-macOS.zip`，双击解压。
2. 将 `CodexQuotaBar.app` 拖入“应用程序”（`/Applications`）。在启用登录启动前，先完成这一步；不要一直从下载目录运行。
3. 打开应用。它没有主窗口，屏幕顶部菜单栏会出现一个小圆环图标。
4. 若 macOS 提示无法验证开发者：首次尝试打开后，在“系统设置 → 隐私与安全性”中找到对应提示，选择“仍要打开”。只对你信任的下载进行此操作。无需关闭全系统安全保护。

应用目前使用 ad-hoc 本地签名，尚未使用 Apple Developer ID 签名或公证。这与源码是否开源是两回事；对下载来源存疑时可自行构建。[Apple 关于打开未经验证应用的说明](https://support.apple.com/zh-cn/102445)

## 2. 开启定位权限

首次会提示开启辅助功能权限，在“系统设置 → 隐私与安全性 → 辅助功能”允许 **CodexQuotaBar / Codex 额度条**。

也可点击菜单栏圆环 →“开启辅助功能权限…”。如果刚开启后仍未显示，退出并重新打开额度条，再切回 Codex。

不需要屏幕录制权限。工具只通过辅助功能 API 获取窗口 / 控件几何和按钮名称，不读取输入框正文。

## 3. 确认 CLI 登录

打开 Codex 桌面版并登录你的账户。工具优先查找桌面版内的 CLI，再查找 `/opt/homebrew/bin/codex`、`/usr/local/bin/codex` 和 PATH。

若菜单提示“未找到 Codex CLI”，先按 [Codex 官方安装说明](https://github.com/openai/codex#installing-and-running-codex) 安装 CLI，再在终端执行：

```bash
codex login
```

登录与桌面版相同的 ChatGPT 账户。必要时在额度条菜单选择“选择 Codex CLI…”，指定 `codex` 可执行文件。找不到文件时可在终端执行 `command -v codex` 查看位置；文件选择框中按 `⌘⇧G` 输入所在目录。

切回 Codex，等待几秒钟。读数完成后，会在输入框底部空白处显示：

`周剩余 69% | 时钟 6天15小时 | 日历 10/10 14:16`

这是示例。实际数据属于你自己的账户。日期统一为北京时间，约每 60 秒读取额度。空间不足时隐藏具体日期，再精简倒计时；完整数据在悬停提示和菜单栏中查看。

## 4. 自动跟随启动

点击菜单栏圆环，勾选“随 macOS 登录启动”。如出现系统批准提示，进入“系统设置 → 通用 → 登录项与扩展”允许它；菜单里也有“在系统设置批准登录启动…”。

以后登录 Mac 时工具自动运行，Codex 未打开时静默等待。打开 Codex 后显示，切换到其他软件时隐藏。开启一次即可；移动应用后需要重新设置。

取消勾选会关闭以后登录启动，不立即退出当前程序。选择“退出额度条”可结束本次运行，下一次系统登录仍按登录项设置启动。

该功能使用 macOS 原生 `SMAppService` 登录项。[Apple 登录项 API](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp)

## 5. 已运行但看不到额度条

依次检查：

1. 顶部菜单栏是否有圆环图标；没有就重新打开 `.app`。
2. 辅助功能权限是否已开启，Codex 是否在前台、窗口是否最小化。
3. 菜单中的状态是否提示 CLI 路径或登录错误；修复后选择“立即刷新”。
4. 输入框底部是否有足够空间，尝试扩大 Codex 窗口。
5. 如果提示“暂未找到输入框”，选择“手动校准位置”。关闭提示后切回 Codex，将额度条拖到输入框底部空白处，右键选择“完成校准”。位置按窗口比例保存；窗口布局大改时可重新校准。

“恢复自动定位”会取消校准，重新使用控件几何定位。应用更新可能改变 Codex 辅助功能结构；自动定位不会猜一个位置覆盖按钮。

读取失败会保留上次成功的数据并标记待更新；到达重置时间并不代表接口已经确认满额。部分账户不返回额度时会说明，没有数据不会造出数字。

## 更新与移除

更新前先退出额度条，用新版本替换“应用程序”里的旧 `.app`，重新打开。macOS 可能要求重新确认辅助功能权限或登录项。

移除前先取消“随 macOS 登录启动”，再退出应用，将应用移到废纸篓。仅本工具的位置、CLI 路径和额度类型偏好保存在 macOS 用户偏好中，不需要删除 Codex 的账户文件。
